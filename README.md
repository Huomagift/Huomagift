## 🔌 Embedded Systems Projects

### [GSM-Based Automatic Window Blind System](https://github.com/Huomagift/gsm-window-blind-system) · *Final Year Project*
Remote and automatic window blind control over GSM, with ambient light sensing and motor control.
- Remote **OPEN / CLOSE / STOP** commands via SMS
- Automatic mode (LDR light sensing) and manual mode, with limit switches for end-of-travel protection
- Built and tested under different operating conditions

`Arduino UNO` `Embedded C` `SIM800L GSM` `LDR` `L298N Motor Driver`
